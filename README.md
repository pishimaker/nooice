# 隐私政策

**生效日期：2026 年 6 月 1 日**

## 1. 信息收集

Nooice 高度重视您的隐私。本应用主要运行在本地设备上，我们收集的信息极少：

- **本地训练数据**：您创建的训练计划、训练记录、身体信息等数据仅存储在您的设备本地数据库中，不会自动上传至任何服务器。
- **AI 服务配置**：如您使用 AI 助手功能，您自行配置的 API 密钥和接口地址将安全存储在设备的加密存储中。
- **设备信息**：我们不会收集您的设备标识符、位置信息或其他个人可识别信息。

## 2. 信息使用

收集的信息仅用于以下目的：
- 为您提供训练计划管理、动作浏览、训练追踪等核心功能
- 调用您配置的 AI 服务以提供智能训练建议
- 改善应用体验和功能优化

## 3. 信息存储与安全

- 所有训练数据存储在您的设备本地 SQLite 数据库中
- API 密钥等敏感信息使用系统级安全存储（Keychain / EncryptedSharedPreferences）
- 我们不会将您的数据传输至任何第三方服务器
- 请妥善保管您的设备，以防他人访问您的训练数据

## 4. 信息安全与跨设备同步

- 应用支持通过 JSON 文件导出/导入训练数据
- 导出文件为明文 JSON，不含加密保护，请谨慎存储和传输
- 请勿将导出的个人数据分享给不信任的第三方

## 5. 儿童隐私

Nooice 高度重视儿童隐私保护。

- **不收集儿童信息**：本应用不会收集任何儿童（13 岁以下）的个人信息，无论是否知情。
- **不面向儿童**：本应用不面向 13 岁以下儿童设计或营销，所有功能均为成人健身训练设计。
- **无儿童数据存储**：应用本地数据库、加密存储及任何导出文件中均不会包含儿童相关数据，因为我们从根本上不收集此类信息。
- **家长/监护人权利**：如您认为您的孩子向我们提供了个人信息，请通过下方联系方式与我们联系，我们将立即删除相关数据。

## 6. 第三方服务

- 本应用不集成任何第三方分析 SDK 或广告 SDK
- AI 助手功能需要您自行提供第三方 AI 服务提供商的 API 访问凭证，数据由您直接发送至该服务商，请参阅对应服务商的隐私政策

## 7. 政策更新

我们可能会不时更新本隐私政策。更新后的政策将在应用内公布。

## 8. 联系我们

如对本隐私政策有任何疑问或建议，请通过应用内反馈渠道联系我们。
