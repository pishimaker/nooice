# 隐私政策

**生效日期：2026 年 6 月 18 日**

## 1. 信息收集

Nooice 高度重视您的隐私。本应用的核心数据主要运行在本地设备上，我们对个人信息的收集保持最小化原则：

- **本地训练数据**：您手动创建的训练计划、训练记录、身体信息等数据存储在您的设备本地数据库中。
- **AI 助手输入数据**：当您使用 AI 助手功能时，为了向您提供智能训练建议，应用会收集您在对话框中主动输入的文本内容、您的运动目标偏好以及您在应用中记录的去标识化（匿名化）身体基础数据（如：身高、体重、健身经验等级、性别）。
- **AI 服务配置**：如您选择使用“自定义 API”功能，您自行配置的个人 API 密钥和接口地址将安全存储在设备的加密存储中。
- **设备与身份信息**：我们不会收集您的真实姓名、手机号码、电子邮箱地址、设备唯一标识符（UDID/UUID）、精确定位信息或其他个人可识别信息。

## 2. 信息使用与第三方 AI 数据处理

收集与传输的信息仅用于以下目的：

- **核心功能提供**：为您提供训练计划管理、动作浏览、训练追踪等基础功能。
- **内置 AI 服务支持**：当您使用默认的“内置 API”时，上述“AI 助手输入数据”将通过加密通道传输至我们合作的合规第三方人工智能技术服务商（包括但不限于 OpenAI、DeepSeek 等）的服务器，以实时为您计算、生成和修改运动计划。
- **数据严格脱敏与不训练声明**：我们**绝不会**向第三方 AI 服务商传输您的任何核心个人身份信息。所有传输的数据均无法与您的真实物理身份进行关联。根据我们与服务商的技术协议，此类数据**不会**被用于其人工智能大语言模型的训练或改进，亦不会用于广告追踪、画像分析或任何其他商业目的。
- **自定义 AI 服务**：如您切换为“自定义 API”，数据将根据您自行配置的接口直接发送至对应服务商，本应用不触碰亦不存储该数据。

## 3. 信息存储与安全

- **本地存储**：所有训练数据存储在您的设备本地 SQLite 数据库中。
- **敏感信息保护**：自定义 API 密钥等敏感信息使用系统级安全存储（Keychain / EncryptedSharedPreferences）。
- **传输安全**：应用与 AI 服务商之间的数据传输均采用行业标准的加密传输协议（HTTPS），防止数据在传输过程中被窃听或篡改。
- **风险提示**：请妥善保管您的设备，以防他人访问您的本地训练数据。

## 4. 数据可携性与导出安全性

- **数据导出与迁移**：为保障您的数据可携权，应用支持导出/导入训练配置数据（包括用户自定义动作、训练计划），以便您在不同设备间迁移或备份数据。
- **加密与安全责任**：导出文件采用 PBKDF2 + AES-256-GCM 高强度加密算法。您在导出时需自行设置解密密码，导入时须输入相同密码。请注意：该密码及加密备份文件均保存在您的本地设备或您自行指定的存储介质中，本应用不收集、不存储该密码。 密码一旦丢失将导致备份数据彻底无法恢复，请您务必妥善保管。
- **导出数据范围**：导出的数据仅包含您在应用内生成的自定义数据（自定义动作和训练计划），不包含应用内置的预设动作库以及您的训练历史记录。
- **数据覆盖规则**：导入数据时，系统采用增量机制，不会覆盖当前设备已有数据。若存在重名的训练计划，系统将自动添加后缀以示区分；若存在重名的自定义动作，系统将默认跳过并保留本地版本。
- **第三方风险提示**：请勿将您的加密备份文件或解密密码分享给任何不信任的第三方。因您自行泄露密码或分享文件导致的个人数据泄露及损失，需由您自行承担。


## 5. 未成年人与儿童隐私保护

Nooice 高度重视未成年人及儿童的隐私保护。本应用包含人工智能生成内容（AIGC）辅助功能，适用于 12 岁及以上用户。

- **儿童隐私（13 岁以下）**：本应用不会明知而收集任何 13 岁以下儿童的个人信息。所有核心健身训练功能 and AI 助手并非面向 13 岁以下儿童设计。
- **无儿童数据存储**：应用本地数据库、加密存储及任何导出文件中均不会包含儿童相关数据，因为我们从根本上不收集此类信息。
- **监护人权利**：如您是家长或监护人，且认为您的孩子向我们提供了个人信息，请通过下方联系方式与我们联系，我们将立即删除相关数据并停用相关功能。

## 6. 第三方 SDK 声明

- 本应用致力于纯净体验，**不集成**任何第三方的广告 SDK、行为分析 SDK 或追踪型第三方组件。
- 仅在调用默认 AI 服务时存在必要的数据传输（详见第二条说明）。

## 7. 政策更新

我们可能会根据应用功能的调整或法律法规的变化，不时更新本隐私政策。更新后的政策将在应用内公布并生效，请您定期查阅。

## 8. 联系我们

如对本隐私政策有任何疑问、建议，或对您的数据隐私有任何主张，请通过应用内反馈渠道与我们联系。
